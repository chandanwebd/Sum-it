### Project facts
- **Stack:** static multi-page HTML + vanilla JS on Cloudflare Pages, plus Pages Functions in `functions/api/*` (`signup`, `stats/public`, `laposta-webhook`).
  - There is no `package.json`, no build step, no TypeScript and no lint. Validate in the browser: console errors, horizontal overflow at 320–1920px, interaction checks.
- **Backend:** Supabase.
  - Tables: `blog_posts`, `content_overrides`, `signups`, `admin_users`.
  - Admin check: RPC `is_admin()`.
  - Config: `sb-config.js`, `config.js`.
- **Languages:** NL default, EN via `/i18n.js` + `window.PAGE_I18N`. The homepage has its own `I18N` object in `js/index.js`.
  - `setLang()` replaces the innerHTML of `[data-i18n]` elements, so never put extra markup inside those elements.
- **Font:** DM Sans. **Design tokens:** `css/tokens.css`.
- **Local preview:** a small Node static server, e.g. `node serve.js <repo> 5173`, with `.claude/launch.json` pointing at it. Use absolute paths like `/components/...`, so the site must be served from its root.
